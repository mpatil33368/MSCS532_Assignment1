# MSCS532_Assignment1

This repository contains a Python implementation of the Insertion Sort Algorithm that sorts an array in monotonically decreasing order.

## Description

The program implements the Insertion Sort algorithm discussed in Chapter 2 of *Introduction to Algorithms*.  
Instead of sorting in increasing order, this implementation sorts the array in monotonically decreasing order.

## Files

- `insertion_sort.py` — Python source code for the insertion sort algorithm

## How to Run

Make sure Python is installed, then run:

```bash
python insertion_sort.py
```

## Example Output

```text
Original Array:
[12, 5, 8, 19, 1, 25, 7]

Sorted Array in Monotonically Decreasing Order:
[25, 19, 12, 8, 7, 5, 1]
```
